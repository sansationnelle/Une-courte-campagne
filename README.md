# Une courte compagne
Ceci est Le site web pour Une courte Campagne, un jeu de plateau physique à la donjon et dragon
Un jeu de 2 à 5 joueurs où votre objectif est d'attaquer les autres joueur et d'être le dernier survivant
# Installation
```bash
npm install, 
npm audit fix (si une erreur de critique s'affiche)
```
```bash
npm run dev
```
